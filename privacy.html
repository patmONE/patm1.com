The app Privacy

Privacy policy

PM1 Home Assistant is a personal app. I, Patrick, am its only user. It is not offered to anyone else.

What the app does with Google data

  • Google Drive. The app uploads backups of my Home Assistant and encrypted backups of my personal notes server to my own Google Drive. It uses the narrowest Drive permission, so it can see only the files it made itself. It removes its own old backups.
  • Nest thermostat. The app reads my thermostat's state and changes its settings, so I can control it from Home Assistant.

Sharing

No data is shared, sold or used for advertising. No other person or company receives it.

The use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage

The app's sign-in tokens stay on my own computers at home. The backups stay in my own Google Drive.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. The app's files can be deleted in Google Drive.

This website

This site uses no cookies, no analytics and no forms. It is hosted on GitHub Pages, and GitHub may log visitors' IP addresses for security.
